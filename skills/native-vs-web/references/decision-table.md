# Decision table

| Need | Web | Hybrid (Ionic/Capacitor) | Fully native |
|---|---|---|---|
| No install for users (guests, one-time use) | Best | Poor | Poor |
| One codebase, small team | Best | Good | Costly (more platforms) |
| App store presence | No | Yes | Yes |
| Deep platform features (widgets, background work, new OS APIs) | Limited | Plugins, may lag | Best |
| Startup and scrolling feel | Fair | Good | Best |
| Offline | Limited | Good | Good |
| Cost to maintain over years | Low | Medium | Higher, but falling with agents (unproven) |

Use the table as a starting point, then check it against a prototype.
